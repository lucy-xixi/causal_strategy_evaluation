# 因果策略评估平台

这是一个作品集项目：在一份**模拟的**地区—月份面板上，评估“部分地区开始发放运营补贴之后，单位用户收益有没有变化，以及这个变化能否写成策略效应”。结果用于展示识别、估计和报告，不是企业真实成效。

## 背景

模拟情景是一个运营平台。某些地区从同一个月份开始实施补贴，其余地区始终不实施。业务上要分开回答五件事：

1. 实施之后，结果的样本表现是否变化。
2. 在地区固定效应、月份固定效应和平行趋势等假设下，有多少变化可以写成处理地区的平均效应。
3. 这个效应在 core、growth、emerging 三类地区中是否不同。
4. 结论对协变量、时间窗口和安慰剂设定是否敏感。
5. 现有证据能支持什么样的下一步。p 值本身不是扩大实施的决定。

面板是 48 个地区、24 个月，共 1152 行。月份 0–23 对应 2022-01 到 2023-12。补贴从第 12 个月（2023-01）开始。处理地区一共 20 个：core 4 个、growth 8 个、emerging 8 个。没有交错采纳。

## 估计目标和识别假设

基础模型是：

```text
outcome ~ treated_post + C(region_id) + C(month)
```

标准误按 `region_id` 聚类。区间和双侧 p 值使用 t 分布，自由度是地区数减 1。

在平衡面板、统一处理时点、处理后效应不随事件时间变化时，`treated_post` 的系数是**处理地区等权**平均处理效应。按本设计的类型效应计算：

```text
(4 * 6 + 8 * 3 + 8 * 1) / 20 = 2.8
```

这不是三种类型效应的简单平均 `(6 + 3 + 1) / 3 = 3.333...`，也不是按全部地区数加权的 `(18 * 6 + 18 * 3 + 12 * 1) / 48 = 3.625`。地区固定效应吸收时间不变的水平差异，月份固定效应吸收共同趋势、季节性和共同冲击；它们不会把这个目标改成另一种加权。

数据生成时没有系统性的处理前差异趋势，也没有预期效应。`region_baseline` 不随时间变化，被地区固定效应吸收，不进入主模型。`promo_intensity` 的生成不使用处理变量；主模型故意不控制它，稳健性模型才加入它。更完整的生成规则写在 `src/config.py` 的 `IDENTIFICATION_NOTES`。

## 安装与运行

开发时使用的是已经安装好的 Anaconda Python 3.13.5，没有为这个项目升级包。`requirements.txt` 把当时的版本固定下来，其中包含 `streamlit==1.51.0`。

```bash
pip install -r requirements.txt
streamlit run app.py
python -m pytest -q
```

页面左侧可以改数据种子和虚假处理组重复次数。虚假处理组使用与数据相同的种子。第一次估计会重复拟合，之后同一组设置从缓存读取。

## 种子 42 的主要结果

下面是种子 42、虚假处理组重复 30 次时，直接运行估计函数得到的结果。页面和自动报告会按当前种子重新计算，不读取这张表里的数字。

基础双重差分：估计 **2.879**，聚类标准误 0.516，95% 区间 **[1.840, 3.917]**，p = 1.168e-06。样本量 1152 行、48 个地区、处理地区 20 个、对照地区 28 个，t 自由度 47。与设计目标 2.800 的差是 0.079。

事件研究的处理前联合检验使用 11 个处理前系数：F(11, 47) = 1.216，p = 0.3033。不显著并不证明平行趋势。基准期是相对时间 −1，图上的菱形是省略约束，不是估计为零。

| 设定 | 估计 | 95% 区间 | p 值 | 行数 | 月份 |
| --- | ---: | --- | ---: | ---: | --- |
| 加入 promo_intensity | 2.866 | [1.843, 3.890] | 9.661e-07 | 1152 | 0–23 |
| 实施前后各 6 个月 | 3.325 | [2.044, 4.605] | 3.943e-06 | 576 | 6–17 |
| 实施前后各 3 个月 | 2.724 | [1.432, 4.016] | 0.0001035 | 288 | 9–14 |
| 安慰剂时间 | -0.009 | [-1.218, 1.199] | 0.9875 | 576 | 0–11 |

安慰剂时间只使用真实实施月之前的观测。它接近零，只说明这个虚假时点没有再现基准效应。

虚假处理组在每个 `region_type` 内保持原来的处理名额，重复 30 次。分布均值是 0.103，真实估计 2.879 的尾部比例是 0.000。这是模拟分布中的位置，不是识别假设的 p 值。

分类型估计：

| 类型 | 估计 | 95% 区间 | 未调整 p | Bonferroni p | 处理 / 对照 | 行数 | 聚类数 |
| --- | ---: | --- | ---: | ---: | --- | ---: | ---: |
| core | 5.621 | [3.208, 8.034] | 0.0001312 | 0.0003935 | 4 / 14 | 432 | 18 |
| growth | 2.640 | [1.562, 3.717] | 7.694e-05 | 0.0002308 | 8 / 10 | 432 | 18 |
| emerging | 1.870 | [0.299, 3.441] | 0.02382 | 0.07146 | 8 / 4 | 288 | 12 |

交互模型以 growth 为参照，参照组系数是 3.138。这个数字和分组回归里的 2.640 不相同，因为交互模型的月份固定效应用的是全部地区。core 减 growth 是 2.274，区间 [-0.005, 4.553]，p = 0.05052。emerging 减 growth 是 -1.786，区间 [-2.980, -0.592]，p = 0.0042。组间相等的联合检验是 F(2, 47) = 8.157，p = 0.0009103。原假设是各组效应相等，不是各组效应为零。

这些类型真值 6、3、1 只存在于模拟设计中。带噪声的一次估计不会正好等于真值。

## 如何读图

- **分组趋势**：每个点是该月处理组或对照组的平均结果。它还没有扣除地区水平和共同季节性，所以不能把它读成双重差分。
- **基础 DiD**：横线是聚类标准误下的 95% 区间。竖线是零效应。
- **事件研究**：圆点是已估计的相对时期，竖线是 95% 区间。菱形位于基准期的零点，只表示该期被省略。处理前系数不显著，不能写成“平行趋势已经成立”。本图只对应统一处理时点。
- **稳健性区间**：每一行是一个成功拟合的设定。安慰剂时间应该和基准效应分开看；它接近零不是“基准结果不稳健”。
- **虚假处理组直方图**：浅色柱是重新分配处理标签后的估计，竖线是真实分配的估计。尾部比例描述这条竖线在柱状分布中的位置。
- **分类型区间**：每一行是该类型自己的处理地区平均效应。组间是否不同，要看交互项和联合检验，不能只比较各组 p 值谁更小。

## 模拟数据声明

所有地区、月份和结果都由固定种子生成。种子 42 的数字可以复现，但换一个种子会得到另一组噪声。设计目标 2.8 是生成数据时写入的处理效应，真实业务数据没有对应的已知真值。报告里把“数据直接显示的事实”“模型估计”“依赖假设的解释”和“尚不能确定的事项”分开写。

## 统计限制

审查统计代码后，估计模块没有发现需要修改的阻断性问题。限制仍然在：

- 聚类数是 48，分组后是 18 或 12。这里使用的是常规聚类稳健方差和 t(G−1)，不是 CR2，也不是 wild cluster bootstrap。有限聚类下区间可能偏窄。
- 地区和月份虚拟变量很多，全部系数的聚类协方差可能不满秩。单个区间只使用对应系数的方差；联合检验只使用被检验系数的协方差子矩阵，子矩阵不可逆时不报告 p 值。
- 处理前联合检验不显著，不能证明平行趋势。安慰剂时间接近零，也不能证明平行趋势。
- 虚假处理组的尾部比例步长是 1/重复次数。重复 30 次时，它只能以约 0.033 的粒度变化。
- 分组回归和全样本交互模型回答的不是同一个估计。参照组在两种算法下的点估计可以不同。
- core 只有 4 个处理地区，emerging 只有 4 个对照地区。Bonferroni 调整没有处理这些检验之间的相关性。
- 事件研究只适用于统一处理时点，不适用于交错采纳。
- 一次带噪声的抽样里，部分处理后事件时间的区间可以覆盖零，即使数据生成时的效应是常数。
- 数据里没有成本、溢出和外部有效性。效应相对结果水平的大小，也不能代替成本是否划算。

因此，种子 42 的基准区间不包含零，协变量和缩短窗口后的方向也与基准一致，但建议只限于讨论**范围有限的后续试验**。不能根据 p 值自动决定扩大实施。

## 作品集说明

这个项目展示的是：先写清估计目标，再用可复现的模拟数据检查估计是否对准这个目标；把质量问题留在检查结果里，而不是悄悄删行；对事件研究、安慰剂和异质性使用同一套聚类区间；最后用 Streamlit 和自动报告把事实、估计和尚未证明的假设分开。

它不展示真实企业因果效应，也不展示交错双重差分、机器学习异质性或自动决策。阅读代码时，估计逻辑在 `src/`，页面只负责调用。

## 后续可以做什么

若继续扩展，优先考虑的是预先登记的后续试验、实施成本和外溢，而不是再增加一个显著性检验。推断上可以比较 CR2 或 wild cluster bootstrap。设计上可以单独做交错采纳；那需要另一套估计量，不能把现在的双向固定效应直接拿去用。
